# RD-004 — Project CRUD vertical slice

## Task brief

Add a shared protected workspace and complete owner-scoped project CRUD. Every read and mutation had to verify the session and explicitly filter by the verified owner in addition to database RLS. Invalid or cross-owner identifiers had to produce the same generic unavailable result.

## Develop handoff

Develop moved dashboard and projects under a shared route-group layout, added responsive authenticated navigation, implemented the owner-filtered project list, and created validated server actions for create, update, and delete. Inserts derive `owner_id` exclusively from verified claims; update/delete chains include both `id` and `owner_id` and inspect selected IDs to identify zero-row results without disclosing ownership.

The UI includes create/edit forms, loading/empty/error states, pending feedback, and explicit deletion confirmation. Proxy coverage was extended to project routes. The final suite contained 61 tests.

## Testing verdict

**APPROVED — review round 1.**

Testing independently traced the PostgREST chains and confirmed the action mocks reproduce the real update/delete response shape. It verified owner-scoped reads, normalized owner-derived inserts, ID plus owner mutation filters, generic zero-row behavior, proxy redirects/headers, form accessibility, deletion cancellation, and route-group output. No BLOCKER, MAJOR, or MINOR findings remained.

Remote authenticated writes were deliberately not executed because the hosted migration and evaluator user are external integration steps. Browser control remained unavailable; UI review used source, CSS, component rendering tests, build output, and local HTTP redirects.

## Orchestrator verification

The Orchestrator inspected the actions, verified-auth helper, server-rendered project page, and React client boundaries. The data path is explicitly scoped at both application and RLS layers, raw provider errors are not returned, and interactive client components are limited to navigation/forms/error boundaries.
